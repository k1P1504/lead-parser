# Парсер клиентов (сайты и софт)

Ищет заказчиков в 4 источниках и складывает результаты в `data/*.csv` + общий `data/leads.xlsx`.
Повторы автоматически отсекаются — при каждом запуске в файл попадают только новые лиды.

## Программа с меню

После установки просто наберите в терминале:

```bash
leads
```

Откроется меню: запуск всех источников, просмотр лидов с поиском и страницами, статистика,
экспорт в Excel и **Настройки** — пошаговые мастера Telegram (ключи → вход → поиск чатов по слову)
и карт (ниши, города, ключ 2ГИС с проверкой). Ctrl+C во время поиска — вернуться в меню.

Команды ниже работают и без меню (удобно для cron):

| Команда | Что делает |
|---|---|
| `python leads.py freelance` | Свежие заказы с FL.ru (RSS) по ключевым словам |
| `python leads.py telegram` | Ищет «нужен сайт / бот…» в публичных Telegram-каналах (режим web, без входа) |
| `python leads.py telegram --watch` | Проверяет каналы каждые N минут и присылает лиды через вашего бота |
| `python leads.py maps` | Компании по нише и городу из 2ГИС и OpenStreetMap (телефон, сайт, email) |
| `python leads.py sites` | Заходит на сайты компаний: контакты + проблемы сайта (нет HTTPS, не адаптивный, старый копирайт…) |
| `python leads.py all` | Всё сразу + Excel |
| `python leads.py excel` | Собрать все CSV в `data/leads.xlsx` |

## 1. Установка (Ubuntu)

```bash
cd ~/lead-parser          # папка, куда распаковали архив
chmod +x install.sh
./install.sh
```

Дальше все команды запускаются так: `./venv/bin/python leads.py <команда>`
(или `source venv/bin/activate`, а потом просто `python leads.py ...`).

## 2. Настройка — файл `config.yaml`

- **keywords / stop_words** — по каким словам ловить заказы и что отбрасывать.
- **maps.niches / maps.cities** — какие ниши и города искать.
- **maps.dgis_key** — ключ 2ГИС: зарегистрируйтесь на https://dev.2gis.ru → «Получить ключ» (есть бесплатный демо-ключ на ограниченный объём). Без ключа работает только OpenStreetMap.
- **maps.only_without_site: true** — оставить только компании *без сайта* (самые тёплые лиды для разработки сайтов).
- **telegram.api_id / api_hash** — https://my.telegram.org → API development tools → создать приложение. При первом запуске Telegram спросит номер телефона и код (сессия сохранится в `data/`).
- **telegram.chats** — список чатов (username без @). Подберите живые фриланс-чаты и чаты предпринимателей своей ниши; примеры в конфиге — заглушки.

## 3. Рабочий цикл

1. `maps` → получили базу компаний с телефонами и сайтами.
2. `sites` → для каждого сайта узнали проблемы; колонка **score** = число проблем. Сортируйте по убыванию — это ваши первые звонки/письма.
3. `freelance` и `telegram --watch` → входящие заказы, на которые надо откликаться быстро.

## 4. Автозапуск по расписанию (cron)

```bash
crontab -e
```
Добавьте (биржи каждые 15 минут, Excel раз в час):
```
*/15 * * * * cd ~/lead-parser && ./venv/bin/python leads.py freelance >> data/cron.log 2>&1
0 * * * *    cd ~/lead-parser && ./venv/bin/python leads.py excel >> data/cron.log 2>&1
```
Telegram в реальном времени — в отдельном окне терминала или через `nohup ./venv/bin/python leads.py telegram --watch &`.

## Важно

- 2ГИС подключён через **официальный API**, а не скрапинг страниц — так не банят.
- Если лента биржи перестала отдавать заказы, скрипт напишет об этом — обновите URL в `config.yaml`. У Kwork RSS нет, Habr Freelance закрылся в 2025 г.
- Холодные рассылки: пишите компаниям лично и по делу (152-ФЗ и закон «О рекламе» запрещают массовый спам на email/телефон без согласия). Лучше звонок или персональное письмо с конкретной проблемой их сайта из колонки `notes`.

## Email-рассылка и фоновая работа

Меню → `r Рассылка`.

1. **5 Почта и подпись**: лучше отдельный ящик. Нужен *пароль приложения*, а не основной пароль. В конце мастер отправит тестовое письмо вам же.
2. **2 Предпросмотр**: посмотреть, какие письма уйдут. Тексты лежат в `templates/no_site.txt` и `templates/site_problems.txt`.
3. **9 Автоотправка: включить**.
4. **10 Фоновый автозапуск → install**, или в терминале `./autostart.sh install`.

Что работает в фоне (systemd, без sudo, пока вы вошли в систему):
- `leads-watch`: постоянное слежение за Telegram-каналами, новые посты приходят в бота;
- `leads-auto` каждые 30 мин: биржи (новые заказы в бота), проверка ответов, отправка писем;
- `leads-daily` в 08:00: карты, анализ сайтов, Excel, сводка за день в бота.

Правила рассылки: одно письмо на адрес и на компанию; не больше `daily_limit` в день; случайные паузы;
только с `hour_from` до `hour_to` по будням. Если пришёл ответ, бот сообщает о нём, и этому адресу больше
не пишем. Отказы («нет», «не пишите») сами попадают в `stoplist.txt`. Журнал отправок ведётся в `data/outreach.csv`.

CLI: `leads.py outreach [--dry-run]`, `leads.py replies`, `leads.py auto`, `leads.py daily`,
`./autostart.sh status|logs|remove`.
