Шаблоны писем рассылки. Первая строка — «Тема: ...», дальше текст письма.
no_site.txt        — компаниям из карт без сайта (если у них есть email)
site_problems.txt  — компаниям, у сайта которых найдены проблемы (Анализ сайтов)

Подстановки: {company} {city} {niche} {website} {problems} {signature} {from_name}
{problems} — список проблем сайта человеческим языком, по строке на проблему.
